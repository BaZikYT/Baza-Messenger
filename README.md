# Волна — свои сервера, каналы, друзья, ЛС и звонки

Веб-приложение: вход по паролю, **свои сервера** с каналами (как в Discord),
**личные сообщения** с друзьями (как в Telegram), голосовые/видеозвонки 1-на-1.

## Что внутри

- `server.js` — сервер на Express + Socket.io: авторизация, серверы/каналы,
  друзья, чат-сообщения, личные сообщения и сигналинг для звонков.
- `data/*.json` — аккаунты, серверы, каналы, участники серверов, заявки в
  друзья. Пароли хранятся захешированными.
- `public/` — фронтенд на чистом HTML/CSS/JS.

**Важно:** сами сообщения (в каналах и в личке) хранятся только в памяти
сервера и исчезают при перезапуске — это осознанное упрощение учебного
уровня. Для реального продакшена нужна БД (см. ниже).

## Как запустить

```bash
npm install
npm start
```
Открой `http://localhost:3000`, зарегистрируйся. Для полноценного теста
заведи **два** аккаунта (два браузера/вкладки-инкогнито).

## Что уже работает

### Сервера (как в Discord)
- Крайняя левая колонка — иконки твоих серверов + 🏠 «Домой»
- Кнопка «+» — создать свой сервер или вступить в чужой по коду приглашения
- У каждого сервера свой набор каналов; владелец сервера может добавлять
  новые каналы («+ Добавить канал» внизу списка)
- Код приглашения виден всем участникам сервера — нажми на него, чтобы
  скопировать и переслать другу

### Друзья и личные сообщения (как в Telegram)
- Раздел «👥 Друзья» (на вкладке 🏠 «Домой»): заявки, принять/отклонить,
  список друзей
- У каждого друга — кнопка 💬 «Написать»: открывает приватный чат 1-на-1,
  который видите только вы двое
- Онлайн-друзьям дополнительно доступны кнопки звонка 🎙️/📹 прямо из списка

### Звонки
- Голосовой и видеозвонок 1-на-1: входящий звонок, принять/отклонить,
  выключить микрофон/камеру, завершить звонок

### Авторизация
- Регистрация и вход по паролю (bcrypt-хеш, пароль никогда не хранится
  открытым текстом), сессия на 7 дней, кнопка выхода

## Важно про безопасность (для продакшена)

- Замени `secret` в `server.js` (в `session(...)`) на длинную случайную
  строку из переменной окружения
- `data/*.json` — не настоящая БД: при большом числе пользователей и
  одновременных запросах возможны потери данных. Для реального проекта —
  PostgreSQL, MongoDB и т.п.
- Сообщения не персистентны (см. выше) — для реальной переписки нужно
  хранить историю в БД, а не в памяти процесса
- Для звонков и в целом для использования в интернете (не localhost)
  обязателен HTTPS
