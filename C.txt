# Волна — сервера, каналы, группы, сторис, звонки и голосовые сообщения

Веб-приложение в стиле Discord + Telegram: вход по паролю, **сервера** с текстовыми и голосовыми каналами,
**группы** для друзей, **личные сообщения**, **сторис**, **голосовые сообщения**, **звонки 1-на-1** и
**голосовые каналы** (mesh WebRTC).

## Что внутри

- `server.js` — сервер на Express + Socket.io: авторизация, профиль, серверы/каналы,
  группы, друзья, сторис, чат-сообщения, личные и групповые сообщения, сигналинг для звонков.
- `data/*.json` — аккаунты, серверы, каналы, участники, заявки в друзья, сторис, группы,
  **сообщения** (теперь сохраняются и переживают перезапуск).
- `public/uploads/` — загруженные аватары, баннеры, сторис, голосовые сообщения.
- `public/` — фронтенд на чистом HTML/CSS/JS.

## Как запустить

```bash
npm install
npm start
```
Открой `http://localhost:3000`, зарегистрируйся. Для полноценного теста
заведи **два** аккаунта (два браузера/вкладки-инкогнито).

## Что работает

### 🔐 Авторизация и сохранение аккаунтов
- Регистрация и вход по паролю (bcrypt-хеш), сессия на 7 дней
- **Все аккаунты, серверы, друзья, группы и сообщения сохраняются в JSON-файлах**
  и не теряются при перезапуске сервера

### 👤 Профиль (редактор + просмотр чужого)
- **Редактор профиля**: загрузка аватара 📷, баннера, изменение имени, статуса и описания (bio)
- **Просмотр профиля любого пользователя**: клик по имени в чате, списке друзей,
  списке онлайн или участников сервера — открывает профиль с аватаром, баннером,
  статусом, описанием, датой регистрации и кнопками действий (написать, позвонить, добавить в друзья)

### 📸 Сторис
- Загрузка фото/видео в сторис (видны друзьям 24 часа)
- Просмотр сторис друзей с прогресс-барами и автопереключением
- Удаление своих сторис

### 🏠 Сервера (как в Discord)
- Крайняя левая колонка — иконки серверов + 🏠 «Домой»
- Кнопка «+» — создать сервер (с аватаром) или вступить по коду приглашения
- **Текстовые и голосовые каналы** (как в Discord) — владелец может добавлять каналы обоих типов
- Код приглашения виден всем участникам — нажми, чтобы скопировать
- Список участников сервера в правой колонке

### 👥 Группы
- Кнопка «👥» — создать группу из друзей (с аватаром и выбором участников)
- Группы имеют текстовые и голосовые каналы, как серверы
- Участники видят группу в крайней левой колонке

### 💬 Сообщения
- Текстовые сообщения в каналах серверов, групп и в личных сообщениях
- **Голосовые сообщения** 🎤 — запись прямо в чате, отправка в любой чат
- **Все сообщения сохраняются** и доступны после перезапуска

### 📞 Звонки
- **Звонки 1-на-1 из чата**: кнопки 📞/📹 в шапке личного чата
- Голосовые и видеозвонки, входящий звонок с принять/отклонить
- Выключение микрофона/камеры, завершение звонка
- **Голосовые каналы** на серверах и в группах — присоединяйся и общайся с несколькими людьми (mesh WebRTC)

### 🟢 Онлайн (исправлено)
- Список онлайн теперь **персонализированный**: видны только друзья и участники
  твоих серверов/групп — а не все пользователи системы

## Важно про безопасность (для продакшена)

- Замени `secret` в `server.js` на длинную случайную строку из переменной окружения
- `data/*.json` — не настоящая БД: для реального проекта — PostgreSQL, MongoDB и т.п.
- Для звонков и использования в интернете (не localhost) обязателен HTTPS
- Для голосовых каналов в продакшене нужен TURN-сервер (не только STUN)
